# Plew 言語仕様

Plew は、複雑な状態を持つクライアントアプリを主軸に、モノレポでサーバも同じ言語で書けるフルスタックのアプリケーション言語です。設計の拠り所は「**人間が唱えた魔法が、その意味の通りに発現する。複雑な魔法の仕組みは隠蔽される**」── 意味は唱えた通り（暗黙変換なし・曖昧はエラー）、発現のコスト（CoW・ARC 等）は裏に隠します。型安全性・非同期プログラミング・パターンマッチング・独自の拡張システムを重視し、シングルプロセス・シングルスレッドを基本とし、JavaScript ライクな非同期処理を採用します。値は値意味論（CoW）、メモリは ARC（参照カウント）で管理し、必要なときだけ opt-in の所有権（`unique`/`local`）を使います。

本仕様書はトピック別に分割し、論理依存順に **4 部 17 章** へまとめています。左のサイドバーから各章へ移動できます。

- **第Ⅰ部 言語の基礎** — 概要・基本構文 / 基本型 / 値・変数・所有権 / 関数
- **第Ⅱ部 型システム** — 構造体と列挙型 / ジェネリクス / メソッドと impl / トレイト / 拡張 / newtype
- **第Ⅲ部 式・制御・エラー** — 制御構造 / 型変換と演算子 / エラーハンドリング
- **第Ⅳ部 実行モデルとツール** — 非同期処理とメモリ管理 / モジュール / メタプログラミング
- **付録** — サンプルコード

> この仕様書は Plew の現在の設計を反映しています。言語仕様は活発に策定中です。

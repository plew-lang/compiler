# Audit and supervise native builds used by normal validation

Inventory native compile/optimization/link paths reachable from the normal suite and required sanitizer variants. Repair the demonstrated physical-signature hidden link/dSYM path and homologous required paths as one bounded work unit, reusing shared supervision and preserving all assertions, debug information and60-second no-progress handling.


## Contract and finite scope

Inventory every native build route reachable from tests/harness/test.sh,
including its case workers and delegated Python/shell helpers. Record entry,
producer command owner, compile/opt/link stages, supervision/logging, debug
packaging and sanitizer variants. Distinguish live build commands from tool
queries, simulated commands, runtime deadlines and manual-only diagnostics.
Follow helpers rather than counting keyword hits. Unchanged safe paths need
source evidence; each defective path needs an assigned repair in this task.

Consolidate genuinely shared test-build supervision/command construction at
scripts/support, preserving caller-specific optimization/sanitizer/ABI flags,
stdout/stderr assertions, input identities, debug object information and failure
publication rules. Use existing trace-command/process_watch; do not introduce a
new supervisor, heartbeat or relaxed idle deadline. Avoid implicit macOS dSYM
packaging in correctness harnesses by compiling debug objects then linking.

## Guarantees and scenarios

- Physical-signature and homologous required native builds forward real work
  to the standard observer and retain artifacts/diagnostics.
- Build progress can continue beyond total60seconds; actual inactivity still
  terminates at60seconds. Error/signal/cancellation fail and children are reaped.
- Exact normal/ASan assertions and sanitizer checks remain unchanged; retain
  selected LLVM provenance and source-specific optimization flags.
- Intentional test deadlines and fake monitoring-negative controls are not
  rewritten as ordinary live builds.
- Inventory coverage and shared-helper consumers are independently reviewed;
  run meaningful integration RED/GREEN and actual affected LLVM20/LLVM22 gates.
- Resume the full normal gate on the unchanged measured compiler, distinguishing
  pre-existing compiler failures from observation/build failures.

## Excluded

Language, ABI/runtime semantics, compiler optimization policy, test removal,
weaker assertions/verifier, main/seed/carrier promotion and unrelated manual
harness expansion. Existing failures remain their existing owners. This task
may close its finite monitoring repair with scoped gate evidence; it does not
certify the whole compiler green or phase3 complete.

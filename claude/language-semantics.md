# 言語セマンティクス（実装者向けダイジェスト）

`SPEC.md`／`spec/*.md` が**意味論まで含めた正典**（機構の詳細と例はそこにある）。本書はそれを実装者向けに再構成したダイジェストで、**機構を再掲せず**次の二つだけに絞る：

1. **章をまたぐ設計の背骨** — 個々の spec 章には現れない、決定どうしの繋がり。
2. **実装で間違えやすい罠** — spec を素直に読むと取りこぼす／逆に取りやすい点を、spec の該当箇所へのリンクつきで。

各判断の根拠・却下案・未決は [design-decisions.md](design-decisions.md)、文法との差分は [grammar.md](grammar.md)。**詳細を知りたくなったら必ずリンク先（spec が正典）へ。**

## 設計の背骨（3点）

1. **値意味論 + CoW + ARC + opt-in 所有権**。これが全制約の根（→ [spec/03](../spec/01-basics/03-values.md)）。代入・受け渡しは独立コピー（CoW で遅延）・共有可変は `Ref` のみ・メモリは ARC（循環は `WeakRef`）。`val` の不変性が信頼でき、並行性は「借用は async/spawn 境界を越えず・spawn は move/copy のみ・`Ref` は spawn 不可」で**実質 race-free**（→ [spec/14](../spec/04-execution/14-concurrency.md)）。文字列の CoW 不変性・`Mutex` 非提供・拡張の値非改変・`deinit` による決定的な資源解放なども、ここから演繹的に出てくる。
2. **拡張解決は呼び出し位置の `#Extension` だけで決定論的に決まる**。import スコープに依存しない（→ [spec/09](../spec/02-type-system/09-extensions.md)）。実装上は「素の呼び出し＝無名 impl＋既定拡張のオーバーロード集合／`#Ext` を書いたときだけそのビューを開く」。一意に定まらなければコンパイルエラー。
3. **メタプログラミングはユーザー定義可能（方針転換中）**：ビルドと独立した別コマンドで別ファイルへコード生成し、マクロは `TokenStream` を入出力する構造体（`Derive` 実装）。実装はコンパイラ完成後の最後（→ [spec/16](../spec/04-execution/16-metaprogramming.md)）。

## 実装で間違えやすい罠（spec 索引つき）

トピックごとに、spec を読むだけだと踏みやすい点だけを挙げる。**機構そのものはリンク先が正典**。

### 値・束縛 → [spec/03](../spec/01-basics/03-values.md)
- すべて**値意味論（CoW）**（代入・受け渡しは独立コピー・共有可変は `Ref` のみ）。可変記憶域は `mut val`／アクセスは `borrow`/`inout`/`move`（呼び出しもモードを echo）→ [spec/03](../spec/01-basics/03-values.md)。`unique`/`local`・`Ref`/`WeakRef`/`->`・`deinit` も同章。
- **再宣言（shadowing）は無制限**で、`name` は常にレキシカルに直近の宣言を指す。`guard`/`match`/`if` の絞り込みはこの一般規則の帰結＝**特別扱いしない**（代入 `x = e`＝既存 `mut` の同型更新とは別概念）。
- **未初期化宣言は無い**（確定代入解析を持ち込まない）。`val x: T` 後分岐代入は `val x = if … { give … }` で書く。

### ブロック・制御フロー → [spec/11](../spec/03-expressions/11-control-flow.md)
- ブロックを式にするには **`give` 必須**（`val x = { 42 }` はエラー、`{ give 42 }` が正）。`if`/`match`/`loop` も式（`loop` は `break <expr>`）。
- **`match` は網羅必須（Rust 流）**：全値がいずれかのアームに当たらないと**コンパイルエラー**（式なので結果値の無い経路を許せない）。enum は全バリアント・`Bool` は両方・整数/`String` 等の開いた型は `_`（or 捕捉束縛 `val x`）必須。**上から順・最初の一致のみ**（fall-through なし）、到達不能アームは警告。**アームにガードは無い**ので網羅判定は純粋に構造的（Rust の「ガード付きは網羅に数えない」例外が不要）。発散アーム（`_ => panic`）もパターンはカバーに数える。
- **`panic` は発散する文**（式ではない＝`x ?? panic` 不可）。全経路が `panic`/`return`/`break`/`continue` で抜けるブロックは値を生まず `give` 不要で、任意の期待型に適合する（`if`/`match` の発散アーム）。`spawn` 内 panic はプロセス全体を停止。
- **条件チェーン**：`if`/`elif`/`while`/`guard` の条件は `&&` 連結の節列で、各節は Bool 式 or 反証可能束縛 `PAT = expr`（Rust let-chains 流）。束縛節は `&&` のみ（`||` 不可・Bool 節内の `||` は自由）。`guard` 本体は発散必須。
- 束縛は `val`＝新規・bare＝既存。refutable（`match`/`if`/`while`/`guard`）は bare＝マッチ。punning `{ val x }`≡`{ x: val x }`。名前位置の葉は 3 種＝`val x`（新規）／bare `x`（既存マッチ）／**`_`（破棄）**。
- **`_` は一般ワイルドカードパターン**（match 専用でなくパターン位置ならどこでも・`Some { value: _ }`・`(val x, _)`）＝束縛を作らない破棄・**書き込み専用シンクで値式不可**（`val x = _` 不可）。**構造体/レコード/バリアントを開く分解は全フィールド明示必須**（束縛 or `_`・残り無視 `..` なし）＝Rust の「全フィールド or `..`」から `..` を抜いた形で、フィールド追加時に既存パターンがエラー化し静かな取りこぼしを防ぐ。

### 型・メソッド解決 → [spec/07](../spec/02-type-system/07-methods-impl.md), [spec/06](../spec/02-type-system/06-generics.md)
- **メソッドはオーバーロード可**：セレクタ（名前＋順序付きラベル）→ 具体位置の型で解決。同セレクタ内は「型引数の形が全員一致・具体位置でのみ区別・制約は曖昧化に使わない」。**無名 impl が型のモジュールに閉じる**ので衝突検出はローカルで完結（グローバルコヒーレンス不要・重なり得るジェネリック impl は保守的拒否＝specialization 無し）。
- **デフォルト引数（`arg: T = 式`）は呼び出しごとに再評価**（Python の定義時 1 回共有ではない＝`= []` は毎回フレッシュで参照共有の罠なし）。式は**定義側モジュールのスコープ**で評価（呼び出し側の名前ではない・非公開も参照可）・**他引数や `self` は参照不可**（自己完結・評価順依存を持ち込まない）・任意の実行時式可（const 限定でない）。**ラベル必須ゆえ末尾限定なし**（途中だけ省略も一意）。`inout` 引数は不可。**省略の組み合わせごとに呼び出しセレクタが増え**（`f(a:b:)`＋`f(b:)`）通常のオーバーロード集合に合流＝別宣言と型で区別できない衝突はコンパイルエラー。 → [spec/04](../spec/01-basics/04-functions.md)
- 型パラメータ `[...]` は**名前のみ**・制約は全部 `where`（述語は `型: 制約` のみ・型等価 `T = I32` は無い）。impl 導入の型変数は `impl[T] Type …` と前置宣言。

### 数値リテラル・演算子 → [spec/02](../spec/01-basics/02-basic-types.md), [spec/12](../spec/03-expressions/12-operators.md)
- **数値リテラルは多相・文脈で確定・既定型なし**（一意でなければエラー＝`val x = 42` も文脈ゼロでエラー）。**変数の後続使用から宣言型を逆算する推論はしない**（期待型を式に下ろす双方向型付けのみ）。
- **負リテラルの先頭 `-` はリテラルに畳み込む**（`Neg` ではない）＝`-128: I8`（最小値）が書ける。`-x`（変数・式）は通常の `Neg`。
- 演算子＝トレイト（`+`=`Add[Rhs]`、`%`=`Rem` …）だが、**`&&`/`||` だけは短絡する制御フロー**（トレイト非・Bool 専用・`if` 糖衣）。`Neg`/`Not` は eager でトレイトのまま（`Neg` は符号付き整数/浮動小数のみ＝`U*` は `-x` がコンパイルエラー）。
- **codegen の罠**：整数オーバーフロー・整数 0 除算は**全ビルドで panic**（意味論を変えるリリースビルドは無い・wrap は `&+`/`wrapping_*` 明示）。NaN を `==`/`<` 等で比較すると **panic**（静かに `false` を返さない）。整数剰余 `%` は truncated（被除数の符号）・`Rem` は**整数のみ**で float 非提供。float `/0.0` は IEEE inf。
- **優先順位は Rust 準拠の 14 段**（`as` ＞ `*/%` ＞ `+-` ＞ シフト ＞ `&` ＞ `^` ＞ `|` ＞ `??` ＞ 比較 ＞ `&&` ＞ `||` ＞ レンジ）。罠：(a) **`as` は算術より強い**（`a as I64 + b` ＝ `(a as I64) + b`）、(b) **前置 `try`/`await` は後置チェーン全体を取る**（`try a.b()` ＝ `try (a.b())`・途中取り出しは `(try a).b()`）、(c) **`??` は Swift 位置＝算術より弱い**（`count ?? 0 + 1` ＝ `count ?? (0+1)`・右結合）、(d) **比較・レンジは非結合**（`a < b < c` 等は構文エラー）、(e) **ビット演算子**＝シフト>&>^>|・全部比較より上（C のバグ回避）、(f) `!`＝Bool 専用 Not・`~`＝整数 BitNot で別物。代入は文なので優先順位に乗らない。
- **複合代入は純粋脱糖・専用トレイトなし**：`a OP= b` ⟺ `a = a OP b`（Rust の `AddAssign` 等は持たない＝所有権が無く脱糖で一様に書けるため）。対象は Rust の 10 個全部＝算術 `+= -= *= /= %=`（`%=` は `Rem` が整数のみ）＋ビット系 `&= ^= |= <<= >>=`。`&&=`/`||=` は無し（短絡制御フローでトレイト非）、`??=` も無し（additive 保留）。罠：(i) **`Output` が左辺型と一致しないと型エラー**（暗黙変換なし＝複合代入で型は変わらない）、(ii) **左辺の場所は 1 回評価**（`arr[f()] += x` は `f()` 一度・`Index`→演算→`IndexSet` に展開）。

### トレイト・準拠 → [spec/08](../spec/02-type-system/08-traits.md)
- **準拠は全要求 `via` 明示**（暗黙準拠なし・`via` 左辺は常に完全シグネチャ・空 impl は準拠失敗）。「名前が合うだけで witness」のうっかり準拠を排除。
- **派生メソッド（`map`/`filter` 等）はトレイト本体にもベア impl にも書かない**：名前付き拡張の `impl Trait` に置き、型が `default_extension` でベア表面に取り込む。上書き不可。
- 継承 `trait Sub: Super` は**制約のみ・自動実装しない**（`impl T as Super` が別途要る）。複数指定は `+`。
- **トレイトを値型にできるのは存在型 `any P` だけ**（裸 `P` 不可・`some` 無し・異種混在・動的）。形成は全型引数/関連型を束縛必須。呼べるメンバはメンバ単位診断（`Self` 入力位置・関連関数は不可）。**実装は最終フェーズ**。

### 拡張 → [spec/09](../spec/02-type-system/09-extensions.md)
- **`A#P` は実行時ゼロコストのビュー**（`A` と同一構造体）だが、型検査では `A` の**不変な型細別**。ビュー変更は常に `#`/`#!` 明示＝暗黙キャストなし・**コンテナ非伝播**（`Array[A]`↔`Array[A#P]` 不可）。拡張違いは別の具体型＝オーバーロード共存（exact 一致）。
- **拡張内 `self` の型は `Foo#Bar` 固定**（呼び出し側の `#A` は本体から不可視）。帰結＝`self.m()` は `#Bar` ビューでの**再帰**（元メソッド呼びではない）、元へは `self#!Bar.m()`（"super" 相当）。
- 継承・ネスト禁止（由来一意性のため）。`T#P` 自体は準拠を主張しない（à la carte 適用）。

### 文字列・配列 → [spec/02](../spec/01-basics/02-basic-types.md)
- `String` は**不変・UTF-8 妥当・`==` バイト等価**。内部は `pub(get) bytes: Array[U8]`（O(1) 読み取り）。`scalars`/`graphemes` はイテレータ（O(n)）・**整数添字 `s[i]` は無い**。
- `Array[T]` 一本（`[E; N]`/Slice/substring は当面なし＝additive 保留・FFI は境界コピー）。**添字 `arr[i]` は `Index[U64]`・`count`・`0..<arr.count` のレンジ要素も `U64`** に統一（暗黙変換なしゆえ同型にしないとキャスト地獄）＝`for val i in 0..<arr.count { arr[i] }` がキャストレス。符号なしで負添字は表現不可・範囲外 panic。**ポインタ幅 `USize` は採らず固定 `U64`**（全ターゲット同一意味論＝Plew の「意味論を変えるビルドなし」と整合・`I32` の 2³¹ 上限も回避）。`String.bytes` は `Array[U8]` なので同じく `U64` 添字。タプルは**ラベル付き無名レコード**（構造的・振る舞いなし）。レンジは `a..<b`/`a..=b` の 2 型への固定 JSX 糖衣・反復は `Step`（整数のみ）。
- **辞書 `Dictionary[K, V]`**：リテラル `[k:v]`/`[:]`（可変アリティで JSX 不可＝配列と並ぶ本物の例外）・**lang item**（リテラルが参照）・キー `K: Hash`（`Hash: Eq`）・**`dict[k] -> V` で欠落 panic**（`Array` 範囲外と同じ＝添字の意味を型で変えない）・安全引きは `get(key:) -> Optional[V]`・代入は挿入/更新（`IndexSet`・`V`）・削除 `remove(key:)`・反復順未規定。集合 **`Set[E]`**（`E: Hash`）はリテラル無し＝**非 lang item**（import 要）。`Hash` 算法は Rust 流 `Hasher`（方向確定・正確なシグネチャは core-lib 送り）。

### モジュール・可視性 → [spec/15](../spec/04-execution/15-modules.md), [spec/05](../spec/02-type-system/05-structs-enums.md)
- **ユーザーは ambient／グローバルな定義を作れない**（全定義はモジュールスコープ・他モジュールは `import` 必須）。ただしトップレベル関数・トップレベル変数（`val`/`mut val`）は在る。static は `assoc fn`/`assoc val`。
- **import 必須の唯一の例外＝言語アイテム（lang item）**：構文が意味として参照する型/トレイト（数値型・`String`・`Array`・`Dictionary`・`Optional`/`Result`・レンジ 2 型・`Add`/`Eq`/`Ord`/`From`/`Iterator`/`Step`・辞書キー境界 `Hash` 等）は常にスコープ＝キーワード同格の語彙。それ以外（`Random`/`Set`/`print`）は明示 import（判定は「構文が参照するか」で sharp。`Set` はリテラル無しゆえ非 lang item）。正確な一覧は TODO。
- 可視性は `pub`/`pub(get)`（型スコープ・2段・中間段なし）と `export`（モジュール境界）の**別 2 軸**。非公開（修飾なし）は**その型の無名 impl からのみ**可視。
- 無名 impl は**型を定義したモジュール内のみ**置ける。外部型への実装はトレイト所有を問わず拡張 `#Ext`。

### 並行性 → [spec/14](../spec/04-execution/14-concurrency.md)
- ランタイムは **ARC**（循環は `WeakRef`）。**借用は async/spawn 境界を越えない**（越えるのは move/copy/Ref）。**spawn は move/copy のみ・`Ref` は spawn 不可**（推移的に `local` でないこと＝Ref-free を要求）→ **スレッド間に共有可変が無く実質 race-free**。**async は単一スレッドゆえ `Ref` 可**（interleave は JS 同様の論理ハザード）。
- ベア `spawn { }` はコピー可能のみ暗黙キャプチャ・`unique` は `spawn fn` の `move` 引数で渡す。`async fn`/`spawn fn` は `-> Promise[T]`/`-> Thread[T]` 明示で `return e` を自動 wrap。
- **実装課題**：境界越えの move/copy/Ref 判定（借用は越えない・`local`-free＝spawn 可否）の型検査。

### エラー → [spec/13](../spec/03-expressions/13-error-handling.md)
- `try <expr>` は `Result` の早期 return 糖衣（特別な例外機構ではない）。エラー型は `From[Source]` 実装があれば自動変換（`try` が `E.from(x: …)` を挿入）。集約 enum の `From` 群はメタプログラミングで生成。
- `x as T` ⟺ `T.from(x: x)`（変換は常にターゲット側 `From[Source]`・ソース型でオーバーロード解決）。
